# Theme

## Compact token summary

- Paper `#fcf9fa`; white surface `#ffffff`; raised/soft surface `#f5e8ec`.
- Primary ink and CTA `#111111`; muted `#66615e`; border `rgba(23,21,18,.16)` / `#d9d9d9`.
- Brand rose `#c94c6b` / `#c96e85`; soft rose `#f3e4e7`; copper `#8d4b5c`.
- Error `#b33c33`; success `#1e6b47`.
- Headings: Georgia/Times serif. Interface: Arial/system sans-serif.
- Auth controls: 48–50px high; modal radius 10px; rose focus ring; black primary CTA.
- Auth modal: maximum 540px, 22px radius, 31–52px responsive padding, blurred dark backdrop.
- Motion: 150–260ms ease with reduced-motion support.
- Breakpoints used across the shell: 420, 520, 700/720/760, 1050/1100 and 1240px.
